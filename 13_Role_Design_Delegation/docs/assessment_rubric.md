# Practical Assessment Rubric — Role-Design & Delegation

Use this rubric for group debrief or quick trainer review.

| Criterion | Strong | Needs work |
|---|---|---|
| Role clarity | Each role has a mission, outputs, decision rights, and stop conditions | Roles are vague or described only as prompts |
| RACI ownership | Every task has clear Responsible and exactly one Accountable owner | Tasks lack owners or multiple roles own final decisions |
| Handoff contracts | Schemas, quality checks, retry, escalation, and logging are explicit | Handoffs rely on vague natural language |
| Incentive alignment | Metrics balance evidence, usefulness, safety, cost, and latency | Team optimizes only speed, cost, or confidence |
| Loop control | Revision limits, escalation, and termination are defined | Critic/writer/planner loops can continue indefinitely |
| Build readiness | Blueprint can become implementation tasks in the next build | Design is still too abstract to code |

Suggested scoring:

```text
5 = implementation-ready
4 = minor improvements needed
3 = conceptually sound but incomplete
2 = major ownership or handoff gaps
1 = not ready for implementation
```
