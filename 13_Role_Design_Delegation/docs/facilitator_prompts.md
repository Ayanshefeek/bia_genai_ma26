# Facilitator Prompts

Use these prompts during discussion.

## Opening

- Where did the previous travel-planner project rely on a manager-worker pattern?
- What went wrong when worker responsibilities were vague?
- Which agent should be allowed to reject final output?

## Role taxonomy

- Is "web search" a role, a tool, or a responsibility?
- Should the Memory Manager be a separate agent or a shared component?
- When does a Planner become unnecessary overhead?

## RACI

- Which task has the highest risk if no one is Accountable?
- Can the same role be Responsible and Accountable?
- What happens when the Fact-Checker is Accountable for final answer quality but the Editor also thinks it is?

## Handoffs

- What field would you require before Writer can draft?
- What field would Fact-Checker need to verify a claim?
- What should happen when the handoff is incomplete?

## Incentives

- What behavior do we get if we reward speed?
- What behavior do we get if we reward confidence?
- What behavior do we get if we reward number of issues found?

## Closing

- Which parts of this blueprint become agent prompts?
- Which parts become routing logic?
- Which parts become schemas or validators?
